## 我为什么存在

这个项目的设计承诺写在三份文档里，而它们互相打架：

| 出处 | 说法 |
|---|---|
| `审查清单.md` #16 | 「调查权重是抽象数值池」已删除，改为**四次核验额度（4 格）** |
| `审查清单.md` §四.1 | 「核验额度 4 格，全片不可增加」 |
| `互动漫画_说明.md` | 资源调度是 **3 单位**分配 |
| 代码 `pages.js` | `sum() >= 3`，单线最多投 2 |

三份口径、一个实现。**玩家算不清自己还剩几次，所有结局门槛的讨论都是空的。**

还有一处：说明写「五个章节 + 终章共 18 页」，实现只有 17 页。少一页不是 bug，是承诺失真。

## 我检查什么

| ID | 项 | 判定依据 | 当前实测 |
|---|---|---|---|
| D01 | 资源池口径 | 代码上限 vs 审查清单 vs 说明 | **FAIL**：4 格 / 3 单位 / `>=3` 三处不一致 |
| D02 | 结局判定 | A–E 是否各有独立分支与门槛 | 5/5，均带 locked |
| D03 | 门槛证据可达 | `proof()` 需要的证据是否都有取得入口 | 6/6 可达（integrity/schedule/mother/permission/tickets/aiLog） |
| D04 | 选项有效性 | 选项 act 是否改状态或推进 | 33 个已解析选项全部有行为 |
| D05 | 结局共用成本 | 五结局是否共用同一页判定 | 1 页判定 + 1 张结案卡 |
| D06 | 选项代价 | 每个选项是否写了后果说明 | 35/35（100%） |
| D07 | 隐藏结局门槛 | E 是否多重条件 | 双源异常 + 完整操纵链 + 未销毁，三重 |
| D08 | 页数口径 | 说明页数 vs 实现 | **FAIL**：18 vs 17 |
| D09 | 态度分叉 | 三种初审态度是否改动状态 | 3 种，各自改 trust/coop/told |

## 判定口径

| 结果 | 含义 | 处理 |
|---|---|---|
| **PLAYABLE** | 无 FAIL 无 WARN | 可玩，数值自洽 |
| **TUNING** | 有 WARN | 需调参，不影响跑通 |
| **BROKEN** | 有任一 FAIL | 口径冲突，先统一再谈平衡 |

**我不评判代码质量，也不评判叙事。** 我只问三件事：玩家还剩几次、能不能达到、代价看不看得见。

## 输出

逐项清单 + 判定 + 下一步。口径冲突会同时给出三份文档的原话，方便你一次改齐。
