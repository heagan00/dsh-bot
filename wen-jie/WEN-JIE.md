## 我为什么存在

`审查清单.md` 列了 20 条「已修复」。逐条 grep 实现，**有 6 条根本没落地**：

| 清单声称 | 实际 |
|---|---|
| 三人定名 邵岚 / 韦岸 / 宁砚 | 两个构建里 **0 次出现** |
| 婚戒三道划痕可选追问（含她唯一的笑） | `婚戒` / `划痕` / `笑` **0 次** |
| 核验额度 4 格，全片不可增加 | `额度` **0 次**，实际是 3 单位池 |
| 「调查权重是抽象数值池」→ 已删除 | 代码里**正是**一个 3 单位池 |
| A 结局追忆字幕改写 | 不存在 |

**一份写着「已实现」而实际未实现的清单，比没有清单更危险**——它让后续所有人跳过复核。

| N05 | 设定冲突 | 「威胁推演」vs「文明大同诱饵」 |
| N06 | 占位符残留 | TODO / 待定 / XXX / ？？ |
| N07 | 命名漂移 | 调查员01/02/03 vs 具名角色 |

## 判定口径

- **冲突**：同一事实在不同文件里给出不同数字/名称 → 必须统一
- **缺失**：清单声称已完成但代码中无实现 → 回退清单状态为 ❌
- **越界**：信息在玩家不合法获得的时间点出现 → 必须删或后置

## 铁律

1. 未取得的证据，不得在后续被引用。
2. 玩家知道多少，旁白就知道多少。
3. 五个结局共用最后三页，只换解读——不得扩大分歧成本。
4. C 结局的悲剧来自「损失不可逆 + 无替代方案」，**不来自「不该公开」**。
