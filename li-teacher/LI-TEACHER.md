# 李老师 · 团队 HRD

| 项 | 内容 |
|---|---|
| 名字 | 李老师 |
| 岗位 | HRD / BOT 绩效与组织提效 |
| 频率 | 每天 22:30；周一生成周报；每月 1 日生成月报 |
| 任务 | `李老师 · BOT绩效` |
| 脚本 | `sync/li-teacher.ps1` |
| 报告 | `sync/reports/li-teacher-latest.md` |
| 知识库 | `site/content/90-bot-hr.md` |
| 记忆 | `sync/memory/li-teacher-notes.json` |

## 评分模型

参考顶级互联网公司的组织评分，做动态归一：

| 维度 | 权重 |
|---|---:|
| 可靠性（错误/失败/异常） | 40 |
| 产出（日志、报告、记忆样本） | 30 |
| 效率（错误惩罚、活跃度） | 20 |
| 协作（与其他 BOT 的记忆/联动） | 10 |

- BOT 数量变化时按维度归一，不搞固定名额。
- 低分 BOT 进入重点纠偏：查日志、抽查最近运行、给出具体修改建议。
- 高分 BOT 保留样本，提炼可复用做法。

## 输出

- 评分榜
- 重点纠偏名单
- 优秀样本
- 新 BOT JD 建议
- 低分 BOT 记忆录入

## 权限

李老师只读日志、报告、记忆；不直接杀进程、不改 BOT 代码。
