# 周哥 · 全栈工程师主程

| 项 | 内容 |
|---|---|
| 名字 | 周哥 |
| 岗位 | 全栈工程师 / 主程 |
| 频率 | **每 5 分钟** |
| 任务名 | `周哥 · 全栈主程巡检` |
| 检查范围 | `~/.dsh/sessions` 中最近 30 分钟活跃的会话 |
| 分析器 | `tools/zhou-ge-analyze.mjs` |
| UI | `sync/zhou-ge.ps1`（主屏上方中间，红色=算力警报） |
| 报告 | `sync/reports/zhou-ge-latest.md` / `.json` |
| 日志 | `sync/logs/zhou-ge.log` |

## 优先级

**最高：算力浪费**

- 同一工具调用重复 ≥3 次
- 30 分钟内模型重试 ≥3 次
- 后台 job 超过 30 分钟未收尾
- 30 分钟内 token 消耗 ≥1.5M
- 多个活跃会话做同一个目标（重复 agent）

**其次：工程路径**

- 25+ step 仍在运行、0 次落盘修改
- 长时间只读/只查，没有最小实现
- 建议：先收敛目标、写最小改动/测试，再继续

## 降噪

- 高优先级 20 分钟内不重复；普通建议 30 分钟内不重复。
- 没有发现问题时**不弹窗**，只写日志。
- 全局 mutex，避免两个巡检实例同时弹。

## 手动

```cmd
schtasks /Run /TN "周哥 · 全栈主程巡检"
powershell.exe -NoProfile -STA -File "sync\zhou-ge.ps1" -NoToast
```

## 边界

周哥读的是 DSH 会话日志的**启发式指标**，不是代码语义审查；它能抓“明显在烧算力/空转”，但不能替代人做架构判断。建议用于提醒，不用于自动杀进程。

弹窗 **30 秒后自动关闭**；也可以点右上角 × 手动关闭。
