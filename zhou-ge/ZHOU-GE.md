# 周哥 · 全栈工程师主程

| 项 | 内容 |
|---|---|
| 名字 | 周哥 |
| 岗位 | 全栈工程师 / 主程 |
| 频率 | 每 5 分钟唤起，**仅在有正在回答的对话时真正巡检** |
| 任务名 | `周哥 · 全栈主程巡检` |
| 检查范围 | `~/.dsh/sessions` 中最近 30 分钟活跃的会话 |
| 分析器 | `tools/zhou-ge-analyze.mjs` |
| UI | `zhou-ge/zhou-ge.ps1`（主屏上方中间，红色=算力警报） |
| 报告 | `zhou-ge/reports/zhou-ge-latest.md` / `.json` |
| 日志 | `zhou-ge/logs/zhou-ge.log` |

## 启动条件

计划任务每 5 分钟唤起一次，但周哥不会无条件巡检。脚本自己有两道门，任一不满足就直接退出：

1. **没有会话写入**：`~/.dsh/sessions` 下最近 `-IdleAfter`（默认 30）分钟没有任何 `session.*.jsonl.zstd` 被写过 → 直接退出，连分析器都不启动。
2. **没有正在回答的对话**：有会话在动，但所有 `turn/start` 都已收平 `turn/end`（没有未收尾的 turn）→ 读档后退出，不弹窗、不写报告、不叫刘哥。

第一道窗取 30 分钟而不是 5/10 分钟，是因为一次工具调用可能十几分钟不写盘；窗太短会把「正在回答」误判成「没人」。第二道只看 turn 是否收尾，不再叠加时间窗——分析器本来就只读 30 分钟窗口内的文件。

只有「一个 turn 已经开问、还没答完」时，周哥才真正巡检。没人对话的时候，它不占算力、不写报告、不打扰。

| 参数 | 默认 | 说明 |
|---|---|---|
| `-IdleAfter` | 30 | 多少分钟没有会话写入就认定没人（与巡检窗口一致） |
| `-SessionsRoot` | `~/.dsh/sessions` | 会话库位置（测试/夹具用） |
| `-Force` | 关 | 跳过这两道门，强制巡检一次 |
| `-NoToast` | 关 | 只输出文本，不弹窗、不叫刘哥 |

## 优先级

**最高：算力浪费**

- 同一工具调用重复 ≥3 次
- 30 分钟内模型重试 ≥3 次
- 后台 job 超过 30 分钟未收尾
- 30 分钟内**新增上下文**（输入 + 输出 + 缓存写入）≥1.5M tokens；缓存读取不计入消耗（它是历史复用，按总量报会把长会话一律判成烧算力）
- 多个活跃会话做同一个目标（重复 agent）

**其次：工程路径**

- 25+ step 仍在运行、0 次落盘修改
- 长时间只读/只查，没有最小实现
- 建议：先收敛目标、写最小改动/测试，再继续

## 降噪

- 高优先级 20 分钟内不重复；普通建议 30 分钟内不重复。
- 没有发现问题时**不弹窗**，只写日志。
- 没有正在回答的对话时**不启动**（见「启动条件」）。
- 全局 mutex，避免两个巡检实例同时弹。

## 手动

```cmd
schtasks /Run /TN "周哥 · 全栈主程巡检"
powershell.exe -NoProfile -STA -File "zhou-ge\zhou-ge.ps1" -NoToast
powershell.exe -NoProfile -STA -File "zhou-ge\zhou-ge.ps1" -Force -NoToast
```

最后一条 `-Force` 是「现在没有正在回答的对话，但我想强制查一次」。默认不带 `-Force` 时，没有进行中的对话就直接返回。

## 边界

周哥读的是 DSH 会话日志的**启发式指标**，不是代码语义审查；它能抓“明显在烧算力/空转”，但不能替代人做架构判断。建议用于提醒，不用于自动杀进程。

## 唤醒刘哥

周哥只在**真要弹窗**时才拉起刘哥复核，不单独定时。找脚本的顺序是：

1. `zhou-ge\liu-ge.ps1`（部署时拷平到同目录）
2. `zhou-ge\..\liu-ge\liu-ge.ps1`（仓库布局）

都找不到就写一行日志明确跳过，不再静默失败。

```text
[时间] liu-ge.ps1 not found (expected .\liu-ge.ps1 or ..\liu-ge\liu-ge.ps1): liu-ge review skipped
```

## 小脑袋瓜记忆（弹不弹的第一道判断）

周哥的记忆不是“备注”，是**弹窗与否的主判断**：先查记忆，再谈限速。

完整链路：

1. 周哥要弹某一类提醒时，拉起刘哥复核；
2. 刘哥判定为误报，弹底部蓝色卡片；
3. 你勾选“同意（刘哥判断正确，记入周哥记忆）”→ 点右上角 `×` → 二次确认点“确认关闭”；
4. 这一步才把结论写入：
   - `memory/zhou-memory.json`
   - `memory/周哥的小脑袋瓜.md`
5. **下次再出现同一个问题，周哥直接不提示**，连弹窗都不给。

三条关键口径：

| 项 | 规则 |
|---|---|
| 记忆键 | 按“同一个问题”记：分析器的 key 去掉会话 id 后归一，例如 `repeat:wait_agent`、`token`；不是整类一刀切 |
| 生效范围 | **跨会话**：换一个会话再犯同一个问题，同样不提示 |
| 什么才算数 | 只有 `agree=true 且 count>0` 的条目才抑制；选了“不同意”、或没关窗的，一律照常提示 |

抑制时日志会写清楚命中：

```text
[时间] memory suppress key=repeat:session-0c47...:wait_agent issue=repeat:wait_agent hit=repeat:wait_agent count=2 last=2026-11-20 12:20:31
[时间] all suppressed by memory
```

全部被记忆压掉时，周哥**不弹窗**，但仍会叫刘哥做一次“重复误报纠偏”，避免记忆把真问题也吃掉。

弹窗**不会自动关闭**，必须点右上角 `×` 手动关闭。
